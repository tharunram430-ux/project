About the System

Phishing Detection Using Machine Learning is a cybersecurity system designed to identify potentially malicious websites.

The system analyzes important characteristics of a submitted URL and uses a trained machine learning model to predict whether the URL is phishing or legitimate.

The system also performs additional security checks and maintains a user-specific scan history.
